# 图像算法与调参（v0.2）

所有像素处理使用独立 C++17 实现；原程序没有源码可对照，故不宣称与原版逐像素相同。以下功能在本机离线运行，参数支持 JSON 保存／载入和批处理。旧版参数文件自动补齐新参数默认值。

## 减色和二值化

先调整亮度／色阶，再选择二值化方法。二值化优先于灰度级数与抖动设置。

| 方法 | 参数 | 使用建议 |
| --- | --- | --- |
| 灰度量化 | 2–256 级，关闭／Bayer 4×4／蛇形 Floyd–Steinberg 抖动 | 纯线稿不抖动；带网点、渐变的漫画可用误差扩散保留平均色调 |
| 固定阈值 | 0–255；像素值 ≤ 阈值为黑色 | 均匀照明下可精确控制笔画粗细，阈值越大黑色越多 |
| Otsu | 自动最大化类间方差 | 黑字白纸、光照均匀的书页；只有一种灰度的空白页避免整页变黑 |
| Sauvola | 局部窗口半径 1–100 px，k=0–1 | 扫描阴影、发黄纸张；默认半径 20、k=0.2，可提高 k 去除背景，但会削弱淡字 |

Sauvola 使用 `T = mean × (1 + k × (stddev / 128 − 1))`。窗口在边缘截断并按实际像素数计算。采用列滚动和横向滑动统计，不建立整页双精度积分图；时间复杂度约 O(像素数)，每个工作线程额外统计内存 O(页宽)。误差扩散沿行串行执行以保留误差传播顺序，其他主要算子按行并行。

PNG／TIFF 的纯二值结果使用真正 1-bit 灰度编码。4／16 级灰度分别使用 2／4-bit 编码；8、32、64、128 和 256 级以 8-bit 灰度保存。JPEG 为有损格式，会在黑白边缘产生中间灰度，不适合要求严格二值的输出。

## 二值化后去毛边

默认关闭，避免误伤小字、网点。仅在启用二值化后执行，输出始终保持纯黑白。

- **孤立黑点**：仅删除 8 邻域内完全孤立的单个黑点，保留相连的细笔画。
- **多数投票**：3×3 邻域多数决定黑白，能平滑边界，但会删除单像素细线。
- **开运算**：黑色前景先腐蚀、再膨胀，去掉向外伸出的细小毛刺。
- **闭运算**：黑色前景先膨胀、再腐蚀，填补内部小白洞和裂隙。

可设置 1–3 次处理。开／闭运算为 3×3 方形结构元；图像边界外视为白纸。优先从 1 次开始，用原图对照检查标点、细横线和小字。

## 横／竖排书页水平矫正

支持横版和竖版画布，选择依据是**文字排列方向**，而不是图像宽高：横排模式对齐水平文字基线，竖排模式对齐垂直文字列。

自动纠斜在最长边不超过 800 px 的分析图上收集墨迹，采用投影集中度搜索，先以 0.25° 粗搜，再以 0.05° 精搜。搜索范围可调 ±1–10°。空白、墨迹过少、深色面积过大或投影得分提升不足 2.5% 时不自动旋转，避免无根据地歪转插画。手动微调为 ±15°，在自动估计角度上叠加；正数顺时针。

旋转使用双线性采样，保持原输出画布大小，外部填白，因此边缘内容可能被裁切。建议先留边、校正后再裁切需要保留的页面。此功能是平面倾斜校正，不是透视矫正或曲面展平。满版插画、文字方向混杂、严重阴影等页面应关闭自动模式并手动调角度。

## 多种锐化与模糊

模糊先执行，随后锐化，再二值化／减色。

| 算子 | 可调参数 | 特点 |
| --- | --- | --- |
| 高斯模糊 | 强度 0–1，半径 1–3 px | 可分离二项式高斯近似，柔和降噪 |
| Box 均值 | 强度、半径 | 可分离方形均值，不同于高斯的权重分布 |
| 中值 | 强度、半径 | 抑制椒盐噪声，比普通均值更保留边缘 |
| 双边 | 强度、半径、色差 σ=1–100 | 按空间距离和亮度差加权，低 σ 更保护明暗边界；彩色图按亮度引导，并非完整色差度量 |
| USM 反遮罩 | 强度 0–2、半径、锐化阈值 | 将原像素与高斯平滑差异加回原图 |
| Laplacian 拉普拉斯 | 强度、锐化阈值 | 使用四邻域高频响应；不使用高斯模糊核 |

锐化差值小于阈值时不增强，用于保护平坦区域噪声。UI 常用范围为 0–64，参数文件允许 0–255。中值／双边比可分离高斯／Box 慢，半径限制为 3 以控制成本。各算法不依赖特定 AVX 指令，可在 Intel 和 M 系列使用。

## 预览、性能和验证

预览最长边 1600 px。滤波半径和局部二值化窗口按当前处理图的像素计算，因此缩略预览和全尺寸导出可能不同；自动纠斜也可能因缩略采样有小幅差异。先导出一页检查，确认细笔画后再批量导出。

自动线程数上限为 8，外层仍逐页处理并释放临时缓冲。最大输入／输出为 4000 万像素；大页高级滤波仍需要数百 MB 内存。没有依赖 GPU 或 Python。

测试包含：阈值边界、Otsu 双峰与空白、Sauvola 对照暴力窗口统计、形态学毛刺／孔洞、滤波的已知像素结果、误差扩散平均色调、横竖版与横竖排 ±3.25° 合成书页纠斜、串并行一致性、小图边界及 ASan／UBSan。macOS 测试覆盖全部二值化模式的真实 1-bit PNG／TIFF 无损往返及旧参数迁移。CI 会在两类 Mac runner 上记录 CPU 处理基准；不应将共享 runner 耗时当作所有 Mac 的性能保证。
