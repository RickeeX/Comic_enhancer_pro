# v0.4 操作栈、书页排版与预览

本项目依据参考软件的公开帮助独立实现，不包含原程序代码。本文区分当前实现与仍未实现的项目，不能视为原软件的逐像素兼容声明。

## 操作栈与逐页参数

每页默认有独立操作栈：**页面 → 色调 → 模糊 → 锐化 → 灰度／减色 → 二值化**。中性参数不会改变图像。二值化默认放在最后的像素转换位置；其内部可选的边缘模板修整在二值化之后运行。

工作台顶部按真实执行顺序列出步骤及参数摘要。选中一行后在下面编辑，展开“完整参数记录”可查看全部配置。可以启停、删除、复制步骤，拖放或使用上移／下移调整顺序，也可以重复添加同一种操作。例如：页面 DPI → 锐化 → 模糊 → 锐化 → 色调 → 二值化。新增普通步骤默认插在二值化之前；独立去黑点默认加入末尾作为后处理。手动拖动不会被系统悄悄改回。

**亮度、对比度、Gamma 并非一般可交换顺序。** 本实现将它们合成一个“色调”步骤以减少遍历，组内固定为自动色阶 → 对比度 → 亮度 → 白点 → Gamma。需要多次色调调整时可复制整个步骤。亮度、对比度、Gamma 以 100 为中性显示，分别对应偏移量 0、倍率 1 和指数 1；不是原版参数文件的数值兼容实现。

若自行把模糊、色调或插值缩放放在二值化之后，可能再次产生灰度，这是显式排序的结果。导出会按最终图像状态选择编码，不会把这些中间灰度强行压成 1-bit。最终仍要纯黑白时，请再在末尾添加二值化。

“应用／复制”支持：全部页面、自选索引区间（如 `0000,0003-0008`）、此页之后的所有页面、整页操作栈复制／粘贴、JSON 预设。应用会复制完整栈和输出配置，不会把页面永久联动。逐页编辑支持最多 50 次撤销／重做；批量应用时，各目标页的旧设置也可逐页撤销。

左侧仅显示从 0000 开始的索引。名称与路径可在悬停提示中查阅。保存书籍工程会记录源文件引用、页面顺序、PDF 模式与导入 DPI、各页操作和参数；工程不内嵌原图，源文件需要保留在原路径。批量导出同时写出 `project.json` 与逐页结果日志。工程与参数 JSON 均为数据，不执行脚本。

## 预览

- 原生滚动视图提供鼠标按住拖动、滚动条、触控板平移和捏合缩放。
- `⌘`+滚轮围绕鼠标位置缩放；`+` / `-` 缩放，`0` 适应窗口，`1` 进入 100%。双击在 100% 与适应之间切换。
- 100% 按实际屏幕缩放因子处理，使一个预览图像像素对应一个屏幕像素。
- 双页模式同时显示相邻两页。可点选任一页编辑，保持当前这对页面；翻页按钮按双页前进／后退。支持右开书交换左右。选中页面有边框与索引提示。
- 辅助网格只供纠斜观察，不写入导出图像。
- 默认预览最长边 1600 px，放大不会自动不断重跑整页算法。检查细笔画请开启“全尺寸”，这时才使用完整输出像素运算。
- 预览改变页面或参数时保留手动缩放和相对视点；适应模式会随窗口和内容尺寸重新适配。双页中未改动的一页复用计算结果，源图另有限量缓存。

滑块拖动仅更改控件内部草稿，松手提交一次。页面尺寸／DPI 数值框输入后按回车生效，避免输入半个数字就启动昂贵重采样。选中步骤或页面后重新初始化编辑草稿，避免把上一页未提交的文字误当成下一页的设置。

## 保持物理尺寸，提高 DPI

“页面”步骤中开启“保持当前物理尺寸，改变 DPI”，输入目标值，例如 600 或 800。它会**真实增加像素**，不只是改文件标签；导出 PNG、TIFF、JPEG 都写入 X/Y DPI。

计算关系为：`物理长度（英寸）= 像素数 / 源 DPI`，`新像素数 = 原物理长度 × 目标 DPI`，像素取整最多带来约一个输出像素的误差。约 300 DPI、12×15 cm 的页面改为 800 DPI 后约为 3780×4724 px，物理页面大小保持不变。插值不能恢复原扫描里不存在的细节，但能提供更多采样点用于后续滤波与二值化。

普通图片优先读取原始 X/Y DPI。PDF 渲染页依据裁切框、旋转与导入分辨率计算。PDF 内嵌图片则解析 `q/Q/cm/Do` 和嵌套 Form 矩阵，依据实际放置尺寸推算两个方向的有效 PPI。原始像素宽高比例与 PDF 页面显示比例不一致时，X/Y PPI 可能不同；提高到统一目标 DPI 时会分别换算两轴，从而保持 PDF 中的物理尺寸。

源信息和最终信息显示在预览下方。没有可用 DPI 时明确提示暂按 300，可指定源 X DPI 和源 Y DPI；Y=0 时跟随手动 X，或沿用自动读取的 Y。相同图片被多次以不同尺寸放置时，当前提取按最大放置面积估计，必要时手动修正源 DPI。复杂 PDF 资源未能解析时也可改用按页渲染获得稳定的物理尺寸。

建议先把 DPI 页面步骤放在前面，再安排模糊／锐化／色调，最后二值化。若要二值化后裁切或排版，可另加一个页面步骤；最近邻缩放更适合保持已有二值，双三次更适合在二值化之前放大。

## 扫描页宽高不一致与排版

页面步骤支持：

- 左／右分页，90°倍数旋转，横排／竖排自动纠斜，手动微调。
- 四边独立百分比裁切与对称裁切；奇偶页可交换左右裁边。
- 自动内容框：灰度阈值、忽略小斑点的最大直径、向外补偿像素；可选择清除与边缘连通的黑区。空白页保持整页范围。
- 保持当前尺寸、指定宽度自动算高、指定高度自动算宽、指定宽高统一整本书、内容框加页边距。
- 厘米／像素单位，A4、A5、12×15 cm 快捷值；独立上下左右边距；奇偶页交换左右边距。
- 等比完整放入并留白、等比铺满并裁切到版心、强制拉伸到版心。只有“拉伸”主动改变内容比例，用于手动修正扫描宽高失真。
- 左中右、上中下对齐；最近邻、双线性、双三次重采样；新增空白填白。

想统一原始 PDF 各页大小，可设置固定物理宽高与目标 DPI，选择完整放入以保留比例，再应用到所有页面；要修正内容拉伸需显式选择拉伸模式。自动裁边、忽略斑点或清除连边黑区可能删掉页码、细线、页眉，默认关闭并建议先单页导出检查。

## 去黑点与温和去毛刺

参考帮助中，“去斑直径”删除长、宽均较小的连通黑区；“边缘去毛刺”则按多种模板修整二值边缘。两个功能不能混为一谈。

**独立去黑点**使用 8 邻域连通分量，只有包围框宽和高均不超过最大直径的区域才删除。另有黑色灰度阈值，可用于灰度图和二值图；直径 0 表示关闭。清除连边黑区是单独的强力开关，不受直径限制。直径过大会删除标点和字内独立点，所以默认关闭。

**温和去毛刺**位于二值化步骤内，以复选框开启。使用四方向的 3×3 hit/miss 模板，只去掉有实心底座的单像素突出点；可选反向模板修补开放小凹口，可运行 1–3 次。它不执行整页多数投票或开／闭运算，不去掉孤立黑点，不填封闭小孔，也不缩掉单像素线条的端点。默认关闭；本实现依据原文描述独立设计模板，不宣称等同原二进制的全部模板。

旧预设中的多数投票／开运算／闭运算不会在新操作栈中重新启用；旧“孤立黑点”可迁移为末尾直径 1 的独立去黑点步骤。

## 其他常用功能与边界

- 任意位置添加和重复镜像、上下翻转、反色。
- 双页可在“预览”菜单水平／垂直拼接导出，间距可调；先执行各页栈，再以第一页 DPI 匹配第二页。拼接图和同名 JSON 记录一起保存。
- 输出可仅用索引命名，或索引加原名，支持前缀及位数；始终导出新文件，不原地重命名源图。名称冲突记录为失败，不静默覆盖前一页。
- 常见原始扫描 PDF 的反向 `Decode` 色彩映射可提取；复杂 ICC／索引色空间、透明蒙版等仍建议使用按页渲染。
- 最大输入／输出 1 亿像素，单边最大 5 万像素。高 DPI 与全尺寸双页预览会显著增加内存，批处理仍逐页执行，原生线程上限 8。
- 缩略图上的自动内容框、滤波窗口与纠斜可能与全尺寸有差异，最终请以单页导出检查。重复 64 个步骤是上限。
- 透视矫正、曲面展平、自动中缝、曲线编辑、高级照度归一、原版全部格式与特殊编解码参数尚未实现。多张任意网格拼接及原地批量重命名也未提供；目前是双页拼接和非破坏式编号导出。当前版本不是完整复刻。
