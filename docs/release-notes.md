**v0.4.1：修复提高 DPI 后内容缩在大画布中央的问题。**

下载 `ComicEnhancer-macOS-universal.zip`，解压得到 `Comic Enhancer.app`。支持 macOS 13+，同一个应用兼容 Intel 与 Apple Silicon／M 系列。

## 修复

PDF 按页渲染时，过去直接把输出像素尺寸作为 PDF 点坐标的适配矩形，高分辨率下可能仅扩大画布，内容没有同步放大，导致缩略预览看起来正常，但开启全尺寸或导出后内容挤在中间。

现在先在 PDF 点坐标中处理裁切框和旋转，再显式缩放绘图上下文至目标像素尺寸，让页面与内容同步放大；不改变既有参数和操作栈顺序。

新增回归会检查内容边界占比，覆盖 PDF 72／144 DPI 渲染、大点尺寸扫描页的缩略／全尺寸一致性，以及保持物理尺寸提高到 400 DPI 后的 PNG 导出。

## 使用

退出旧版，再打开新版，使用原始 PDF 和原操作栈重新预览／导出。错误已经写入旧导出图片的留白不能仅靠更改 DPI 标签恢复，需要从原 PDF 重做。

包含 v0.4.0 的操作栈、逐页参数、物理 DPI、双页缩放预览、温和去毛刺等全部功能。功能边界见 `docs/operation-stack.md`。

发布要求 Linux 核心／内存检查，以及 Intel 和 Apple Silicon 的原生测试、通用构建全部成功。`SHA256SUMS.txt` 可校验下载包。

应用为 ad-hoc 签名，尚未 Apple 公证。确认来源后可按系统提示在“系统设置 → 隐私与安全性”中允许打开。
