**v0.5.0：灰度单通道流水线与Mac多核优化。**

下载 `ComicEnhancer-macOS-universal.zip`，解压得到 `Comic Enhancer.app`。macOS 13+，同一应用兼容Intel和Apple Silicon／M系列。

- 常见灰度书页连续使用Gray8，减少三通道重复计算和整图复制；工作区跨步骤、预览和批处理复用，并限制保留内存。
- Mac使用Accelerate／vImage处理灰度高斯，GCD动态领取行块、复用系统线程；保留便携实现和RGBA回退。
- 高斯／USM混合使用精确LUT；灰度和二值导出直接打包为8／4／2／1-bit。
- 批量导出在CPU与内存预算内最多并行两页，预留文件名、保持页序日志并支持步骤间取消。
- 完成Metal候选评测；CPU优化后GPU收益不稳定，自动校准还未通过ARM批量稳定性检查，因此正式应用采用CPU路径，GPU代码仅保留独立测试。

开发阶段同机完整原生操作栈基准（合成灰度JPEG，约1777万输出像素，包含PNG输出）：Apple Silicon约699→203ms／页，Intel约1907→461ms／页；前后像素指纹一致。用户提供的11张书页另在Linux执行55次前后对照，C++处理及对应复制约755→191ms／页，全部输出逐像素一致。机器、内容和参数会影响结果，不能将这些数字当成任意PDF或真机的保证。

完整方法、原始数据、适用范围与优化后的审核见 `docs/performance-v050.md`。发布要求Linux核心／内存检查、双架构原生测试、后端评测、完整流水线像素对照及Universal构建全部通过。

应用仍为ad-hoc签名，未进行Apple公证或用户真机上的长期性能验证。`SHA256SUMS.txt`可校验下载包。
