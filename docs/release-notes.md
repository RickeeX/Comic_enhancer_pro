**v0.4.2：优化 3000 万像素大图处理，给操作栈加入边框。**

下载 `ComicEnhancer-macOS-universal.zip`，解压得到 `Comic Enhancer.app`。支持 macOS 13+，同一个应用兼容 Intel 与 Apple Silicon／M 系列。

## 大图性能

- 普通像素操作直接采样，省去没有缩放时的通用插值。
- 高斯改用整数可分离核；Box 使用滑动和；5×5／7×7 中值改用两级滑动直方图；双边预计算亮度。
- 双三次使用分离计算和行缓存，放大时复用结果；保持原采样坐标和核，浮点舍入最多相差 1 个通道灰阶。
- 减少 USM、固定／Otsu 二值化的临时空间；不忽略斑点时直接并行查找内容框；二值去毛刺使用等价模板掩码。
- 连续操作借用合格的 sRGB 位图，核心输出直接转交 CoreGraphics，减少整图重绘、复制和无用清零。过期预览在步骤之间取消。

同一 Linux 云主机的 5000×6000 图像基准：高斯约 **3.5×**、方框 **3.4×**、中值 **4.3×**、USM **2.8×**、Otsu **5.0×**。这些是单个核心操作的示例收益，不包含 PDF／图片编解码，也不代表所有参数或设备的总耗时。完整方法、数据和仍然较贵的路径见 `docs/performance.md`；两个 macOS runner 的同机前后对比及原生流水线时间见对应 Actions 摘要。

## 界面与验证

“当前页操作栈”滚动区域增加随系统主题变化的细边框、圆角和浅背景。

核心回归使用独立参考卷积、排序和二维重采样，穷举全部 512 种二值邻域。原生测试增加裁切 provider 的偏移检查、预览取消，以及内嵌 JPEG 的 300→400 DPI 全尺寸／缩略／导出内容占比检查。

**关于此前的 PDF 内容缩小反馈：**v0.4.1 已修复“按页渲染”的独立问题。本版增加“提取内嵌图片”专用回归；可控样本通过不能代替用户原始 PDF 的复现，不把这条路径的问题标记为已定位修复。进一步确认需要原始问题页面和操作栈。

发布要求 Linux 核心／内存检查，以及 Intel 和 Apple Silicon 的原生测试、基准、Universal 构建全部成功。`SHA256SUMS.txt` 可校验下载包。

应用为 ad-hoc 签名，尚未 Apple 公证，尚无用户真实设备上的速度／手感验证。确认来源后可按系统提示在“系统设置 → 隐私与安全性”中允许打开。
