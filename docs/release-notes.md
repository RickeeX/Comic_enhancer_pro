macOS 原生漫画增强工具 **v0.4.0 操作栈与书页工作台**。

下载 `ComicEnhancer-macOS-universal.zip`，解压得到 `Comic Enhancer.app`，拖入“应用程序”后打开。需要 macOS 13+；同一个应用支持 Intel 与 Apple Silicon／M 系列。无需 Python 或 Homebrew。

## 本次更新

- 每页独立操作栈，顶部显示所有步骤和参数；支持拖动排序、启停、复制、删除和多次重复同一操作。
- 应用到全部、自选索引区间、此页之后；整页栈复制粘贴、撤销重做、预设和书籍工程保存。
- 原生缩放、拖动、捏合、鼠标定点缩放、100%／适应与双页预览；点选任一页编辑、右开书、网格、全尺寸检查。
- 保持物理页面尺寸而提高 DPI，真实重采样并写入文件；识别 PDF 内嵌图片的放置尺寸和 X/Y PPI，可手动修正两轴。
- 四边裁切、自动内容框、固定宽高、页边距、对齐、奇偶页镜像边距，以及完整放入／铺满裁切／拉伸排版。
- 独立连通分量去黑点，可调最大直径和灰度阈值；保守模板去毛刺替换前台多数投票／开闭运算。
- 页面列表仅显示索引；亮度、对比度、Gamma 以 100 为基准。
- 镜像、反色、双页拼接和非破坏式编号导出。

默认流程为页面 → 色调 → 模糊 → 锐化 → 灰度／减色 → 二值化。二值化后只在启用时运行局部边缘模板；用户自行排序可能再次引入灰度，想保留纯黑白请把二值化放在最后。

数值框输入后按回车应用。缩略预览不等于全分辨率检查；开启全尺寸或单页导出检查细笔画。高 DPI 不能恢复原扫描不存在的细节。自动裁边、去黑点、去毛刺、连边清除默认关闭，建议先试一页。

## 验证与边界

发布流程要求 Linux 核心／内存检查，以及 Intel 和 Apple Silicon macOS 的图像编解码、PDF、操作栈、DPI、工程和原生预览测试及通用应用构建成功。真实设备的交互手感仍需试用反馈。

本版本仍是独立重写，曲面展平、透视校正等高级算法未完整复刻。详见仓库 `docs/operation-stack.md`。`SHA256SUMS.txt` 可校验 ZIP。

应用仅作 ad-hoc 签名，尚未 Developer ID 签名或 Apple 公证；确认来源后可按系统提示在“系统设置 → 隐私与安全性”中允许打开，不需要关闭系统安全检查。
