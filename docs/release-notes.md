macOS 原生漫画增强工具首个试用版本。

## 下载与运行

下载 **ComicEnhancer-macOS-universal.zip**，解压得到 **Comic Enhancer.app**，可拖入“应用程序”后打开。

- 需要 macOS 13 或更新版本。
- 同一个 `.app` 同时包含 Intel（x86_64）和 Apple Silicon／M 系列（arm64）代码。
- 应用使用优化编译，不需要 Python、Homebrew 或额外运行时。
- `SHA256SUMS.txt` 提供 ZIP 文件校验值。

## 功能

原生中文界面；亮度、对比度、Gamma、白点与自动色阶；灰度与灰度量化；锐化、柔化、裁边、旋转、缩放和左右分页；参数保存与载入；原图对照预览和批量导出。每批导出新建目录，保留原图，并保存处理日志。

## 试用说明

- 此版本仅作 ad-hoc 签名，尚未使用 Developer ID 签名或 Apple 公证。下载后 macOS 可能阻止首次启动；确认来源后，可按系统提示在“系统设置 → 隐私与安全性”中选择“仍要打开”。无需关闭系统安全检查。
- 发布流程要求 Linux 核心／内存检查，以及 Intel 和 Apple Silicon macOS 的核心、编解码集成测试和通用应用构建全部成功。真实设备上的界面交互仍待试用反馈。
- 这是独立重写的初版，尚无透视矫正、曲面展平、自动纠斜、图像拼接等高级功能。动画与多页图像只处理首帧。详见 README。
